## Challenge

Nous avons un challenge pour toi !

Voici la maquette Figma à intégrer. Tu dois :

1. Découper la page (slicing)
2. Réaliser la page en HTML / Tailwind (ou React si tu préfères)
3. Déployer la page sur Vercel ou Netlify
4. Créer une vidéo Loom de 5 minutes maximum pour présenter ton travail

Soumets le lien de ta page déployée + le lien Loom via ton espace candidat.

## Critères d'évaluation :
- Fidélité au design
- Qualité du code HTML/CSS
- Utilisation de Tailwind
- Responsive design
- Présentation claire dans la vidéo
